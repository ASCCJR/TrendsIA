# TrendsIA

Portfólio de projetos desenvolvidos durante a **Capacitação e Residência em
Agentes de IA — TrendsIA**, programa do Núcleo Softex Campinas, dentro do TrendsIT.

Os projetos serão adicionados conforme o avanço na capacitação e os requisitos
de cada entrega.

Cada projeto terá documentação do problema, instruções de execução e evidências
de avaliação, conforme os critérios do programa.

## Status

Organização inicial do repositório. Nenhum projeto implementado ou entregue.
